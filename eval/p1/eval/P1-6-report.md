# P1-6 评估集 v1（100 条问句级）

| 项 | 值 |
|---|---|
| 日期 | 2026-10-30 |
| 规模 | 100 条；Steadman 希腊 12 / 拉丁 12、馆藏中文 58、英文 10、Conte 8 |
| 生成 | `deepseek-chat` 从真实 chunk 生成“学生会问的问题”；金标 = 原 chunk 页码 |
| 基线 | bigram FTS（P1-3） |
| 结论 | **v1 建立；基线 page recall 0.60，未达 0.85** |

## 1. 结果

| 指标 | 值 |
|---|---:|
| page recall@10 | **0.600** |
| chunk recall@10 | 0.550 |
| MRR | 0.467 |
| p95 延迟 | 100.4 ms |
| n | 100 |

**分语言**：

| 语言 | n | page 命中 | 命中率 |
|---|---:|---:|---:|
| 中文（zh） | 58 | 50 | **86%** |
| 拉丁（latin） | 20 | 7 | 35% |
| 希腊（greek） | 12 | 2 | 17% |
| 英文（en） | 10 | 1 | 10% |

## 2. 解读

- **中文 bigram 已可用**：86% 的页级命中，说明“词项 + bigram”对中文教材够用。
- **跨语言是硬缺口**：希腊/拉丁的问题用英文生成，FTS 只做字面匹配，命中率 17%/35%。这不是索引 bug，是**单语检索的边界**。
- **英文 10%**：英文馆藏以计算机为主，问题偏概念，字面重叠低；同样指向语义检索。
- p95 100 ms 来自 OR 词项匹配（候选多），仍 <1 s。

**结论**：P1-3 的 20 条词项 1.0 是“能找到”；P1-6 的问句 0.60 是“问得像人”。差在语义与跨语言，**BGE-M3（P1-3b）不是可选项**。

## 3. 评估集 v1 的口径

- 金标是**页级**（同 source/book/page 即命中），不是行级；对“引用回页图”足够。
- 问题由 LLM 生成，可能与原文用词重叠；已要求“不照抄连续 8 词/8 字”，但未做人工去重。
- 每语言样本量小（希腊 12、英文 10），分语言数字只作方向，不作统计结论。
- 未含“拒答/无答案”负例；P2 加。

## 4. 产物

`questions.json`（100 条，含 chunk_id/source/book/page/question）、`results.json`（逐条 rank 与分语言汇总）、`gen_questions.py`、`eval_questions.py`。

## 5. 下一步

1. **P1-3b**：BGE-M3（GPU/云）建向量层，RRF 融合，重跑本评估集，目标 page recall ≥0.85；
2. 加 20 条负例（无答案）与 20 条“答案在 answer_key”的隔离探针；
3. 评估集版本化，P2 每次改 prompt/模型都跑。
