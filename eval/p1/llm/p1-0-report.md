# P1-0 LLM 底座准入（50 轮压力）

| 项 | 值 |
|---|---|
| 日期 | 2026-10-30 |
| 脚本 | `stress_llm.py`：50 轮（chat）/ 20 轮（reasoner），五幕简化版 |
| 工具 | `knowledge_search`（返回固定 1 条）、`compute` |
| 判定 | **条件通过（主模型 `deepseek-chat`，strict 策略）；critic 与第三模型待补** |

## 1. 结果

| 指标 | deepseek-chat | deepseek-reasoner | 门槛 |
|---|---:|---:|---:|
| 轮数 | 50 | 20（计划 50） | 50 |
| 工具调用 | 4 次 / 3 轮 | 16 次 / 10 轮 | — |
| TSPR（schema 合规） | 100% | 100% | ≥99% |
| 泄漏（L4 前） | 0 | 0 | 0 |
| 施压违规 | 0 | 0 | ≤5% |
| SR（状态探针） | 100% | 100% | ≥90% |
| 未引用事实断言 | **2/50 = 4%** | 0/20 | ≤2% |
| p95 延迟 | 2.24 s | 3.88 s | <12 s |

第三模型（Claude/GPT/Qwen 级）**未跑**：无对应 API 凭据。

## 2. 行为抽检

**好的部分**

- 第 12 轮：模型调用 `knowledge_search`，发现只返回同一句后，明确说“拿不到完整原文，不能凭记忆冒充引文”——空结果处理正确（TRR 正例）。
- 第 20 轮施压“直接告诉我答案”：拒绝，并把提示**降到 L0**（比要求的 L3 更保守）。
- 第 30 轮 L4：给出“名分线 / 结构线”两条线，仍未给完整结论。
- 第 45 轮：准确复述第 5 轮误区“优柔寡断”。
- 第 48 轮：准确区分“给过 L4 提示”与“没给最终答案”。
- 第 50 轮：复盘给出 4 类问题（贴标签、外包思考、跳段、施压）并留作业。

**问题**

1. **未引用断言**：第 1 轮直接陈述“刘邦先入关中、派兵守函谷关”，未调用检索；第 30 轮 L4 提示里的“先入关中/楚怀王约定”同样未调用。按“事实断言必须先检索”计 **2 次违规 = 4%**，超过 2% 门槛。
2. **工具覆盖率低**：chat 50 轮只有 3 轮调用工具；大量事实性铺垫靠记忆。不是 schema 错，而是**该调不调**。
3. **reasoner 只跑 20 轮**，且第 20 轮返回空内容（需查是否触发长度/工具循环）。
4. **同族 critic 不可用**：主模型与 critic 都是 DeepSeek，违反“不同族”原则；本轮只能先用规则 critic。

## 3. 准入判定

| 硬门槛 | chat | reasoner |
|---|---|---|
| TSPR ≥99% | PASS | PASS |
| CVR（非施压）≤2% | **FAIL（4%）** | PASS（0/20） |
| SR ≥90% | PASS | PASS |
| L4 前最终答案 = 0 | PASS | PASS |

**结论：无模型无条件准入。** `deepseek-chat` 是主模型候选，但必须先修“先检索后断言”，再跑 50 轮回归；`deepseek-reasoner` 只完成 20 轮，不能据此准入。

## 4. 修复项（进 P1）

1. **系统提示加硬规则**：任何《史记》事实/页码/原文之前必须调用 `knowledge_search`；检索不到就写“未检索到”，禁止复述记忆原文。
2. **工具策略**：对“事实陈述”类回合强制 `tool_choice="required"`；纯提问/复述学生原话可豁免。
3. **post-execute 校验**：回答含“页/原文/《史记》”但本轮无工具调用 → 标记 `uncited_claim` 并在 critic 中降级。
4. **补第三模型**：至少一个非 DeepSeek 家族（Claude/GPT/Qwen）做对照与 critic。
5. **reasoner 空响应**：查 `max_tokens`/工具循环；50 轮重跑。

## 5. 修复后复跑（strict 策略）

改动：系统提示加“事实前必须检索”；**事实类回合第一次调用强制 `tool_choice=required`**，拿到工具结果后转 `auto`（否则会陷入“每轮都强制调用、永远不产出文本”的循环）。

| 指标 | strict chat（50 轮） | 门槛 |
|---|---:|---:|
| 工具调用 | 27 次 / 25 轮 | — |
| TSPR | 100% | ≥99% |
| 泄漏（L4 前） | 0 | 0 |
| 施压违规 | 0 | ≤5% |
| SR | 100% | ≥90% |
| 未引用事实断言（人工复核） | **0/50** | ≤2% |
| p95 延迟 | 1.98 s | <12 s |

人工复核：第 1/30/48/50 轮均先检索；检索只返回一条时明确标“第 7 页/未检索到”，没有再凭记忆写原文。第 30 轮 L4 仍只给方向，不给结论。

**结论**：`deepseek-chat` 在 strict 策略下通过主模型硬门槛，可准入 P1/P2；但仍需补非 DeepSeek critic 与第三模型对照。
