## 3. 决策

### 3.1 收窄 GO

**MVP 保留**：

- **古典语言**：Steadman（含原文的卷）+ Loeb/Teubner；希腊/拉丁检索、词表、行号、页图引用。
- **理工**：正文/代码/图表入库；公式与推导**只做页图**，计算走 SymPy（键入或高置信 LaTeX）。
- **中文**：OCR 文本仅用于检索与提示；引用一律回页图；**不做逐字引用**。
- **检索层**：自建 `socratic-search`（D4 已验证），P1 换 BGE-M3。
- **引用**：书名/卷/页级 + 页图；满足“书级引用”要求。

**MVP 砍掉**：

- 竖排逐字 OCR（二十四史/十三经/诸子）→ 只做页图 + 卷次索引；
- 现代汉语逐字引用（OCR CER 12%）；
- 公式自动转 LaTeX（等 P1 VLM）；
- 全库 330k 页预处理（按需入库不变）。

### 3.2 触发条件（出现即回退）

| 触发 | 动作 |
|---|---|
| P1 检索 recall <0.85 | 加 rerank / 换 BGE-M3；仍不达标 → 停 |
| 三流金标 <90% | 古典分支只做“原文 + 词表”，注释人工 |
| Conte/West 进入导出/快照 | 立刻隔离，按版权 Gate 处理 |
| 中文 OCR 用于逐字引用 | 阻断发布，回页图 |
| canary 在对话层命中 | 停，修隔离后再继续 |

## 6. 结论

**收窄 GO**：以“古典语言 + 理工正文 + 中文页图检索”为 MVP，先跑通教学闭环；中文/竖排的逐字能力等 VLM OCR 通过后再放开。这不是“降级交付”，而是把**引用级**与**检索级**分开：检索可以脏，引用必须回页图。
