## 1. C1 史记一（p76）

- 列切分：**18 列**，列宽 40–46 px（200 dpi），右起编号 1–18；标注图人工核对，**顺序正确**。
- 页面同时含**正文大字**与**三家注小字**（索隐/正义），二者在同一列内，未分离。
- 逐列旋转 90° 后 OCR：**0–46 字符/列**，内容错乱；3× 放大 + 加白边后仍只有 25–46 字符/列，且多为误识（如 `國江}"又`、`【國震”一作】`）。

## 2. C2 十三经注疏 01（p103）

- 区域切分：9 个区域；首个区域宽 **525 px**，把一整块注疏合并成一块；其余窄列 26–33 px。
- OCR：合并块 549 字符（顺序错乱），窄列 0–24 字符。
- 注疏块与经文块**未分离**。

## 3. Gate C

| 标准 | 结果 |
|---|---|
| 列序 ≥95% | **PASS**（18/18，右起） |
| 注文错分 ≤10% | **FAIL**（未分离，正文/小字同列） |
| CER ≤5% | **FAIL**（无可用竖排 OCR；PP-OCR 旋转后仍不可读） |

**判定：FAIL**。按计划 fallback：

1. **竖排只做页图引用**：入库只存 `page + bbox`，不把 OCR 文本当正文；
2. **P1 换竖排专用方案**：MinerU 2.5 / Qwen-VL 直接读竖排版面，或古籍专用 OCR（识典/如是）；
3. **注文分层**：必须在版面阶段按字号/行宽分出“经/注/疏/校勘记”，不能靠 OCR 文本猜；
4. **检索**：竖排书暂不进入逐字索引；可先做“书名 + 卷/页”级检索。
