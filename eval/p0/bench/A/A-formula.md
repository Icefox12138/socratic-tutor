## 1. A1 Princeton（文字层）

- 60 页窗口（134–193）：平均 **963.8 字/页**，0 空白页，最多 1,246 字。
- 3,704 行中，718 行含 `=`，345 行含数学符号（∫∑√≤≥±×÷∞→∂）。
- 以“左端可被 Python AST 解析”为代理指标：**398/718 = 55.4%**；但真实可编译率更低，因为**版面结构丢失**。

典型损坏：

```
lim
x→∞
sin(x)
x
= 0.
```

（一个极限被拆成 5 行）

```
x sin(11x7) −1
2
2x4
```

（`11x7` 实为 `11x^7`；分子分母被拆行）

**判定**：文字层能拿到字符，但拿不到公式结构；**不能直接转 LaTeX/SymPy**。

## 2. A2 李尚志（扫描）

- OCR 平均 **671 字/页**；10 行含 `=`。

```

a21X1+a22x2+*+a2nn=b2
```

## 3. A3 C Primer（扫描）

**判定**：可做检索/引用，**不可直接执行**；代码需人工或 AST 校验。

## 4. A4 伯克利力学（扫描）

## 5. 数学能力（SymPy）

10 道题（求导、极限、积分、方程、行列式、逆矩阵、级数、tan 导数）**10/10 通过**。说明：**只要输入是结构化表达式，计算层可用**；问题在“从书里可靠地拿到表达式”。

## 6. Gate A 判定

| 标准 | 结果 |
|---|---|
| 文字层公式可编译 ≥90% | **FAIL**（代理 55.4%，结构丢失） |
| OCR 公式 CDM ≥0.75 | **FAIL**（A2/A4 不可用） |
| 表格 TEDS ≥0.85 | 未测（本轮无表格样本） |
| 10 道计算题交 SymPy | **PASS（10/10）** |

**结论：降级通过（conditional_pass_degraded）**。按计划中的 fallback 执行：

1. **公式只做页图**：解析时把公式区域裁图，存 `page + bbox`，不把 OCR 文本当公式；
2. **VLM 提取 LaTeX**：P1 用 MinerU/视觉模型，输出带 `formula_conf`；`conf < 0.9` 禁止进计算（§14.4 已有门控）；
3. **计算只认两类输入**：学生键入的表达式、或高置信度 VLM LaTeX；其余一律“看原页”；
4. **A 分支保留**：正文/代码/图表仍可入库，数学分支不以“公式自动抽取”为前提。
