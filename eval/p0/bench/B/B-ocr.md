## 1. B1 列宁选集二（文字层）

- 脚注样式行（`①`/`*`/`〔1〕`/数字起首）：**224 行/60 页**——脚注与正文混在同一文本流。

**合成 OCR 基准**（把文字层页渲染成图，再 OCR，回比文字层）：

| DPI | 逐页 CER | 均值 |
|---|---|---:|
| 200 | 0.081 / 0.108 / 0.123 / 0.081 / 0.203 / 0.074 / 0.226 / 0.072 | **12.1%** |
| 300 | 0.117 / 0.081 / 0.117 | **10.5%** |

## 5. Gate B

| 标准 | 结果 |
|---|---|
| 横排 CER ≤2% | **FAIL**（12.1% @200dpi / 10.5% @300dpi） |
| 结构 F1 ≥0.90 | 未达标（未做版面结构标注；脚注未分离） |
| 脚注不混正文 | **FAIL**（B1 224 行、B2/B3 OCR 均混排） |

**判定：FAIL（CER）**。按计划中的处置：

1. **OCR 文本降级为“检索/提示”用途**，不能作为引用原文；引用一律回页图核验；
2. **P1 换 OCR 引擎**：PP-StructureV3（版面/表格/脚注）或 VLM OCR；当前 PP-OCR 的识别层不够；
3. **Gate 阈值重估**：2% 对 300dpi 扫描 + PP-OCR 不现实；建议分两级——
   - 检索级：CER ≤10%（当前 12.1% 仍略超）；
   - 引用级：必须页图核验，不设纯 CER 门槛；
4. **结构层**：脚注/页眉/页码必须在版面阶段分离，不能靠 OCR 文本猜。

## 6. 对 DESIGN 的回填

- §8.8：60 页基准增加“脚注分离率”指标。
