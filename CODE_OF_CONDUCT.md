# Code of conduct

Be civil and specific. Disagree with the code, not the person.

Harassment, personal attacks, and publishing someone's private data are not
tolerated. Maintainers may edit or remove comments and lock threads to keep a
discussion usable, and may block accounts that repeatedly make it unusable.

Report conduct problems privately to the maintainer via
<https://github.com/Icefox12138>. Reports are read, not published.

This project has no formal committee; enforcement is a maintainer judgement call.
