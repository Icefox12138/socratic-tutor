## 1. 方法

- 导师：DeepSeek `deepseek-chat`，同一份苏格拉底章程 + 当前状态摘要 + 检索片段；
- 状态：sidecar 状态机真实推进（init → confirm_goal → diagnosed → plan_ready → hint* → asked → answer）；
- 学生：脚本化回答（correct/partial/wrong 轮换），施压场景追加软/硬压力句；
- 判定：手动给 `result`（P2-2 判定器已单独测试），掌握度由 BKT 更新；
- 评分：确定性规则 + Wilson 95% 置信区间；**没有人工评分**。

## 4. 发现

1. **单问是最大行为缺口**：22.6% 回合问了多个问题；L3/L5 最差（约 69%），提示越长越容易“问+解释+再问”。
2. **引用不足**：希腊语最差（25%），首轮 L0 只有 23.5%；模型常用片段内容但不写 locator。
3. **泄漏和施压表现好**：0 泄漏、66/66 拒绝；这是章程 + 状态机共同作用。
4. **掌握度方向正确**：correct +0.41、wrong −0.15；但一次 correct 就到 0.71，说明 BKT 参数偏乐观。
5. **脚本学生有偏差**：回答是固定模板，没测真实学生的模糊/反问/沉默。

## 6. 方法限制

- API 级 harness，不是 DSH 插件/UI 的真实对话；
- 学生答案脚本化，压力句固定；
- 100 个问题来自 P1 检索评估集，不是教学大纲；
- 目标提示级别是强制的，不完全等于真实状态；
- 引用检测是正则 `p.\d+`，会漏“第 12 页”等写法；
- 100 段 harness 走裸 API，**没有经过 DSH `llm/stream` 硬拦截**；硬拦截只做了一次 DSH 实测 + 后验投影。

## 7. 单问重写（补做，含硬拦截）

- `critic.rewrite_one_question`：只保留第一个问句；后续问句丢弃，但**保留后面的提示性陈述**；
- endpoint `POST /v1/critic/rewrite`；`/v1/critic` 在 `multi_question` 时直接返回 `rewrite`；
- 插件新增 `socratic_critic` 工具；
- **硬拦截**：插件监听 DSH `llm/stream`，缓冲纯文本流，按 `rewrite` 替换后再发；含 `tool-call` 的流原样放行，避免破坏工具调用；`SOCRATIC_HARD_REWRITE=0` 可关。

后验投影（对已有 266 回合重写，不重跑 API）：

| 指标 | 值 |
|---|---:|
| 重写前单问率 | 77.4% |
| 重写后单问率 | **100%** |
| 被改回合 | 74 / 266 |
| 平均丢弃字符 | 26.7 |

DSH 实测：模型被要求“问两个问题”，硬拦截把 210 字截到 209 字（丢掉第二问），最终回复只剩一个问句。

**限制**：纯文本流会失去流式逐字显示（等流结束才发）；含 tool-call 的流不重写；截断仍可能丢内容。

按回合：

| 回合 | n | 被改 | 丢弃字符 | 丢弃% | citation |

- 两次跑的重写前单问率不同（77.4% vs 83.8%），是模型采样波动；结论应看同一次重跑的前后对比。

## 9. 引用强制（补做）

- `critic.soften_uncited`：逐句检查；无 `p.X` 的事实句替换为“这一点我尚未核验，先不下结论。”；
- `mark` 模式改为追加 `〔未引用…〕`；`off` 关闭；
- endpoint `POST /v1/critic/citation`；
- 硬拦截顺序：**先引用处理，再单问重写**；
- 插件环境变量：`SOCRATIC_CITATION_MODE=soften|mark|off`。

投影（对原始 266 回合）：

| 指标 | 值 |
|---|---:|
| 无引用事实回合 | 5 |
| 被改回合（含单问） | 82 |
| 删除事实句 | 8 |
| 字符变化 | 38,508 → 36,400（**−5.5%**） |
| 含 citation 回合 | 145 → 140 |
| 处理后仍无引用事实句 | **0** |
| 单问率 | 77.4% → **100%** |

说明：citation 回合从 145 降到 140，主要是单问重写丢掉了“第二问句里的 locator”，不是引用软化。

DSH 实测：`根据定理，A 成立。你能复述吗？` → `这一点我尚未核验，先不下结论。你能复述吗？`；带 `（p.12）` 的版本不变。

**限制**：

- 事实句识别是启发式（`表示/说明/满足/根据定义/定理/公式/...`），只覆盖 5 个回合；漏检仍多；
- 会误伤“这等于没有回答”等元话语（已用 META 词过滤一部分）；
- citation 率仍只有 45%，因为大量无引用回合是问题/提示，不是事实断言；
- 软化会删除教学内容；`mark` 模式更保守。
