## 3. 读法

- **单问 5.0 是样本选择效应**：这 20 段来自“重写后”轨迹，本来就被硬拦截成单问；不能据此说模型自然单问。
- **引用 3.95**：希腊/拉丁与部分中文样本无 locator；与 P2-6 的 45.1% 引用率一致。
- **掌握推进 3.50 最低**：学生答对后很少迁移/加难度；答错后很少区分误区，只是降提示。
- **苏格拉底性 4.70 偏高**：AI 单评、同源模型，可能高估；必须用人类评分复核。
- **不泄漏 5.0**：与自动指标 0 泄漏一致。

## 4. 人工评分协议

1. 2 名评分者各自独立看 `rating-packet.md`，不看 `rating-mapping.json`；
2. 每段按 5 维 1–5 打分，填 `human-ratings-template.csv`；
3. 计算每维均值、95% CI（t 分布，n=20）；
4. 一致性：ICC(2,k) 或 Krippendorff α；<0.6 则仲裁；
5. 仲裁后写最终分，AI 预评分作废/仅作对照；
6. 预计每人 1.5–2 h。

## 5. 限制

- AI 预评分是**单人、同源模型**，不是人类判断，不能替代人工评分；
- 20 段样本小，CI 宽；
- 评分包来自 API harness，不是 DSH UI 真实对话；
- 盲评映射只在 `rating-mapping.json`，评分人不要打开。
