## 1. 结论

P3-2 只到**卷**，这一轮补到**篇**：每卷开头的篇名页（大字号"五帝本紀第一"）被找出来，作为二级索引挂在卷下面。

| 卷 | 篇 | 篇首页 | 页码范围 |
|---|---|---|---:|
| 卷1 | 五帝本紀第一 | p19 | 19–70 |
| 卷2 | 夏本紀第二 | p71 | 71–108 |
| 卷3 | 殷本紀第三 | p109 | 109–128 |
| 卷4 | 周本紀第四 | p129 | 129–190 |
| 卷5 | 秦本紀第五 | p191 | 191–240 |
| 卷6 | 秦始皇本紀第六 | p241 | 241–312 |
| 卷7 | 項羽本紀第七 | p313 | 313–356 |

卷首 1–18、卷末 357–358 保留为一级行；**一级行合计 358 = 全书页数**，篇行嵌在卷内不重复计数。

## 2. 方法

1. 对每个卷边界，只 OCR **start−2 … start+2** 五页（28 页共 ~4 分钟，避免整本 OCR）；
2. 在 OCR 行里找 `(本紀|世家|列傳|書|表)第X`，**取最长的匹配行**（"五帝本紀第一" 优先于被切碎的 "本紀第一"），同长度再比字宽、再比离边界的距离；
3. 篇名页可能比卷眉页早一页：**卷起点跟着前移**（卷一实际从 p19 开始，P3-2 的 p20 是卷眉首次出现的页）；
4. 卷标题合并为"卷1 五帝本紀第一"，篇作为 level-2 行；重排一级范围保证无重叠无空洞。

## 3. 验证

- 篇名页逐一看过：p19（史記卷一 / 五帝本紀第一）、p191（史記卷五 / 秦本紀第五）等；
- 7 个篇名与《史记》本紀顺序一致；
- `/v1/toc` 返回 16 行（9 一级 + 7 二级），一级覆盖 358/358；
- `/browse` 里篇行缩进显示、点击跳转；
- `python eval/p3/browse_check.py` → `OK`。

## 4. 接口变化

`toc` 表的行多了 `level` 与 `parent`：`level=1` 是卷/卷首/卷末，`level=2` 是篇（`parent` 指向卷号）。`/v1/toc` 直接原样返回，前端按 `level` 缩进。纯函数 `toc.merge_pian(chapters, hits, total)` 承担合并与范围重排，被 5 条单测覆盖（起点前移、matter 不降级、篇行紧跟其卷、一级连续、无命中时不变）。

## 5. 复现

```
python eval/p3/render_pages.py --book C1 --dpi 130 --pages "18-21,70-73,108-111,128-131,189-192,240-243,312-315"
```

## 6. 限制

- 每卷只扫边界 ±2 页；若某卷的篇名页离卷眉页超过 2 页会漏（本书是 0–1 页）；
- 本书是"一卷一篇"；一卷多篇的情况（史记的表/书、后世章回小说）未验证，逻辑上支持（篇行按 start 排序、末篇到卷末）；
- 篇名靠 OCR，短标题更易错（"夏本紀第二" 的框宽只有 24，是七篇里最弱的一个）；
- 只做了 C1 一本。
