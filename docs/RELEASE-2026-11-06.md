## 4. sidecar 镜像

```bash

# 或
docker build -t socratic-sidecar:0.2.1 .
docker tag socratic-sidecar:0.2.1 ghcr.io/icefox12138/socratic-sidecar:0.2.1
docker push ghcr.io/icefox12138/socratic-sidecar:0.2.1
```

镜像约定：

- 不带书、不带 BGE 权重；`SOCRATIC_BGE=0`；
- `/data` 可写（SQLite、state.db、cache）；
- `/books` 只读挂载；
