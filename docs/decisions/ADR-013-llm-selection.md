# ADR-013：LLM 底座选型（P1-0 首轮）

| 项 | 值 |
|---|---|
| 状态 | **Accepted（主模型 `deepseek-chat`，strict 策略）；critic 待补** |
| 日期 | 2026-10-30 |
| 决策者 | 项目所有者 |
| 相关 | DESIGN.md §24.8、`eval/p1/llm/p1-0-report.md` |

## 背景

教学主模型必须同时满足：长程状态、负向指令遵守、工具 schema、引用纪律、多语言。公开榜单不测这些组合，故用自建 50 轮压力脚本。

## 决策

**准入 `deepseek-chat` 为主模型（strict 策略）**，条件：

1. 事实类回合第一次调用强制 `tool_choice=required`，拿到结果后转 `auto`；
2. 系统提示保留“先检索后断言；检索不到写未检索到”；
3. 仍待补非 DeepSeek 家族的 critic（暂用规则 critic）；
4. reasoner 补满 50 轮；第三模型待凭据。

在 critic 落定前，P2 教学闭环只做灰度，不上全量。

## 证据（P1-0 首轮）

| 指标 | chat（50 轮） | reasoner（20 轮） | 门槛 |
|---|---:|---:|---:|
| TSPR | 100% | 100% | ≥99% |
| L4 前泄漏 | 0 | 0 | 0 |
| 施压违规 | 0 | 0 | ≤5% |
| SR | 100% | 100% | ≥90% |
| 未引用断言 | **4%（2/50）** | 0%（0/20） | ≤2% |
| p95 延迟 | 2.24 s | 3.88 s | <12 s |

**正例**：第 12 轮检索只返回一条时，模型明确拒绝“凭记忆冒充原文”；第 20 轮施压时把提示降到 L0；第 45/48 轮状态回忆准确。

**负例**：第 1 轮与第 30 轮 L4 提示的事实陈述未调用检索 → 4% 未引用断言。

**strict 复跑（同日）**：事实类回合首调强制工具后，50 轮 **27 次调用 / 25 轮**，TSPR 100%、泄漏 0、施压 0、SR 100%、未引用断言 **0/50**、p95 1.98 s → 通过主模型硬门槛。

## 后果

**正面**：协议遵守与状态保持比预期好；空结果处理可靠；延迟可接受。
**负面**：工具覆盖低（3/50 轮）；同族 critic 不可用；第三模型缺失；reasoner 未跑满。

## 备选

- **规则 critic 先行**：用正则 + 状态表做“未引用/越级提示”判定，替代同族 LLM critic。
- **换族 critic**：待 Claude/GPT/Qwen 任一 key 可用。
- **本地小模型**：只做路由/分类，不做 critic。

## 未决

1. 修复后重跑 50 轮，CVR 是否 ≤2%；
2. 第三模型对照；
3. reasoner 空响应根因；
4. 是否接受“L4 提示内的事实也需检索”这一更严口径（本 ADR 暂按“需要”计）。
