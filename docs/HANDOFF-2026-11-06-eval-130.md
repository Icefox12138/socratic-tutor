## 3. 关键发现

1. **规模改变结论**：43 问/87 chunks 时 bge+词表 0.977；130 问/331 chunks
   只要 0.938。小集偏乐观，不能把小集数字写进结论。
2. **BGE 是主力**：语料变大后 fts+词表只有 0.792，BGE 0.892，bge+词表 0.938。
3. **翻译决定跨语言**：zh→希腊/拉丁从 0 到 1.000/0.917。
4. **LLM 是 OOV 专用**：未知子集 0.625 → 1.000；但在已知词表上
   R@1 0.800→0.738、zh-lexical 0.941、zh-semantic 0.897，反而变差。
5. **提示词决定 LLM 成败**：第一版把 `克鲁塞斯` 译成 Croesus，未知子集
   R@5 0.75；要求“史诗实际词形（-οιο/-ου、-is/-i/-em）+ 别称”后
   （Saturnia、ἀργυρότοξος），8 条全部 top-5。
6. **自动题偏简单**：34 条 zh-lexical 是章节前缀自动生成，几乎送分；
   真正的差异在语义/跨语言/未知。下一轮应减少自动前缀、增加人工语义问。

## 8. 坑

1. CTS 旧端点会拒绝部分行号（Iliad 1.31/1.32、Aeneid 6/7/11/31/32/33）；
   必须 `--skip-errors`，否则整个文档导入失败。
2. 重新入库会**替换**整本文档；扩行时要一次传全量 URN，不能分批追加。
3. `queries-130.jsonl` 的 34 条 zh-lexical 是自动前缀，指标 1.000 不代表真实问答能力。
4. LLM 翻译非确定、~1.6 s/查询；不要在已知词表上无脑开 `llm`。
5. `RESULTS.md`（43 问）与 `RESULTS-130.md`（130 问）口径不同，不要混用。
