## 1. 结论

竖排扫描件没有文本层（实测全书 0 字符），所以索引只能从**版心**（页边书眉）里读。做法是：渲染每页 → 只裁右侧版心条 → OCR → 取"最上方、短、含卷字"的那一行 → 按卷分段。

| 章 | 页范围 | 页数 |
|---|---|---:|
| 卷首（目錄/出版說明） | 1–19 | 19 |
| 卷一 | 20–71 | 52 |
| 卷二 | 72–109 | 38 |
| 卷三 | 110–129 | 20 |
| 卷四 | 130–190 | 61 |
| 卷五 | 191–241 | 51 |
| 卷六 | 242–313 | 72 |
| 卷七 | 314–356 | 43 |
| 卷末（附錄） | 357–358 | 2 |

与文件名"卷一至卷七"一致，覆盖 358/358 页，章与章之间无空洞。

## 2. 三个坑（都已处理）

1. **整页 OCR 太慢**：10 s/页 → 358 页近 1 小时。改成裁右侧版心（宽 18%、高 8%–55%），1.2 s/页。
2. **目錄页也写着"史記卷十三/卷二十八…"**：同样出现在裁切区，会把第一卷认成卷十三。规则改为取**最上方**的短"卷"行，并且要求同一卷号连续 ≥5 页（目录页的卷号都是孤页）。
3. **版心不是每页都识别到**：只识别到约一半页。索引不要求每页都有，章的范围由"下一个章起点 −1"推出，因此仍然连续无缝。

## 4. 页图浏览（`/browse`）

- 左栏章回列表，点击跳到该章首页，当前章高亮；
- 右栏页图：←/→ 翻页、页码直跳、"适应宽度"在 150/200 dpi 间切换；
- 顶部显示当前章标题 + 页码；`/ui` 页头有入口链接。

接口：`GET /v1/books`、`GET /v1/toc?source=&book=`、`GET /v1/pages?source=&book=&page=&dpi=`（已有）。

## 5. 管线

```
python eval/p3/render_pages.py     --book C1 --dpi 150          # 需 .venv-bge（pymupdf）
python eval/p3/vertical_header_ocr.py --book C1 --png-dir out/C1_pages   # .venv-ocr
python eval/p3/build_toc.py        --book C1 --source library --shards out/C1_heads.jsonl
```

`build_toc.py` 写两处：`eval/p3/out/C1-toc.json` 和 sidecar 的 `toc` 表（`/v1/toc` 读它）。

## 6. 限制

- **卷级**，没有篇级（本纪/书/表）切分；篇名要等目录页解析或页内标题检测；
- 版心位置是按这本书定的（右侧 82%–100% × 8%–55%），换版式要调 `--crop`；
- 目录页的假卷号靠"连续 ≥5 页"过滤，若某卷真的少于 5 页会被误删（本书没有）；
- 只跑了 C1 一本；C2/十三经等版式未验证；
- 扫描页图仍在 PDF 里，索引只存页码，不搬页图。
