# 仓库资产政策（截图 / 示例数据 / 书页）

| 项 | 值 |
|---|---|
| 日期 | **2026-11-03** |
| 适用范围 | 会进 git 的图片、示例数据、页面片段 |
| 结论 | 代码 MIT；**书页图像不进仓库**，除非有明确许可或属公有领域 |

---

## 1. 为什么单独有这份政策

代码用 MIT 发布，意味着仓库里所有内容都会被默认为 MIT。书页扫描件不能这样处理：

- 点校本（中华书局等）的**点校、排版**是新的著作权；
- 1929 年后的 Loeb 译本仍在版权期；
- 即使是公版古籍，**某次扫描/摄影**也可能有独立权利。

一张截图混进仓库，等于把整份 MIT 声明扩到了那张图上。

## 2. 三类可用素材（按优先级）

| 优先级 | 类型 | 要求 |
|---:|---|---|
| 1 | **自制**（脚本渲染的示例页、终端输出、我们自己造的 demo 数据） | 无第三方权利，直接 MIT |
| 2 | **明确许可**（作者书面同意 / CC BY / CC0） | 在 `docs/assets/SOURCES.md` 记录许可原文与链接 |
| 3 | **公有领域**（1929 年前出版且扫描件标注 PD） | 记录来源、出版年、PD 依据 |

不可用：点校本、现代排印本、1929 后译本、来源不明的 PDF 截图、以及"网上能下载"的讲义（下载 ≠ 可再分发）。

## 3. 关于陈童（东华理工大学）讲义

本机有 9 份陈童讲义（`D:\Guo-Code\PDF\物理\...`）。其中 `量子力学新讲` 的版权页写得很清楚：

> Copyright © 2021 陈童 … 作者本人保有**所有版权**，读者可自由下载、也可**私自传播**，
> 但**仅限用于学习或教学等非商业用途**，禁止以本讲义的部分或全部获利。

判断：

| 用法 | 是否可行 |
|---|---|
| 自己读、自己截图不看别人 | ✅ |
| 放进公开仓库当 README 截图 | ❌ **超出"私自传播"的范围**，且会被 MIT 覆盖 |
| 拿到作者书面许可后使用 | ✅（需在 SOURCES.md 附许可原文） |

若要联系：版权页给了邮箱 `tongchen@ecut.edu.cn`。**在拿到回复之前，不采用。**

## 5. 替换方案

优先级从高到低：

1. **自制渲染**：用 `classics-index` 的示例数据生成一张"索引输出"图（纯文本卡片，零版权）；
2. **公版扫描**：Wikimedia Commons / Internet Archive 上标注 Public Domain 的 1929 年前印本，记录来源与年份；
3. **作者许可**：按 3 联系并保留书面许可。

## 6. 落地规则

- 任何图片进仓库前，必须在 `docs/assets/SOURCES.md` 有一行：文件、来源、许可、日期；
- `scripts/publish_lint.py --scope source` 会检查：仓库里的图片是否都有登记、是否有 ⛔ 标记；
- 示例数据同理：只放自制或公版，且不得包含版权书的整页文本。
